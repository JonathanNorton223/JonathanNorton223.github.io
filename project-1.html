CS 360 - Android Weight Tracking Application

Project Overview

The Android Weight Tracking Application was originally developed in CS 360. The application allows users to create an account, record weight information, monitor progress toward a target weight, and manage stored information through CRUD operations.

For my Computer Science Capstone, I selected this application for the Software Design and Engineering category. The enhancement focuses on improving application architecture, security, maintainability, validation, and error handling.

The enhanced design demonstrates secure password handling, separation of application responsibilities, improved input validation, and software engineering practices intended to make the application easier to maintain and extend.

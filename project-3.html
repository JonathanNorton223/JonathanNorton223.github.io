CS 370 - Pirate Intelligent Agent

Project Overview

The Pirate Intelligent Agent was originally developed in CS 370. The project uses reinforcement learning and deep Q-learning to train an intelligent agent to navigate a treasure-hunting environment while balancing exploration and exploitation.

For the Algorithms and Data Structures category of my Computer Science Capstone, I enhanced the project by replacing random experience replay with prioritized experience replay.

The enhancement uses Temporal Difference error values to prioritize more valuable learning experiences. A priority-based data structure allows the agent to focus on experiences that provide greater learning value, improving the efficiency of the training process.

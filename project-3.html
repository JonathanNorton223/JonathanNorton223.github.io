CS 340 - Animal Shelter Dashboard

Project Overview

The Animal Shelter Dashboard was originally developed in CS 340 using Python, Dash, and MongoDB. The application allows rescue organizations to search and filter animal records and view information through interactive data tables and mapping features.

For the Databases category of my Computer Science Capstone, the application was selected for enhancements involving more efficient database access, MongoDB field projection, improved error handling, optimized query operations, and centralized database management.

These improvements demonstrate database optimization, nonrelational database development, efficient data retrieval, application integration, and user-focused reporting.
